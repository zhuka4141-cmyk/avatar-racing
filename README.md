# 头像赛车（avatar-racing）

浏览器单页自动观赏赛车游戏。按 `2026-09-22-avatar-racing-design.md` 规格实现，并包含后续提出的四项改动（更弯的赛道、更多超车、结算后继续跑、名次可下滑）。

## 在线试玩

- GitHub Pages：https://zhuka4141-cmyk.github.io/avatar-racing/
- 源码仓库：https://github.com/zhuka4141-cmyk/avatar-racing

## 运行

- 直接双击 `avatar-racing/index.html`（file:// 打开即可，页面不发起任何网络请求）。
- 或用任意静态服务器：`python -m http.server 8080`，访问 `http://localhost:8080/avatar-racing/`。
- 头像只在当前页面会话的 Canvas 缓存中存在，不会上传。

## 关键实现

### 状态机

```
setup -> countdown(3.9s，显示 3/2/1/开始) -> racing
racing  --第一名冲线--> waiting（记录 leaderFinishAt，镜头目标切到终点线）
waiting --finishers >= min(10, 参赛人数)--> ending
waiting --waitingElapsed >= 5s---------> ending（按当前进度记录名次）
ending  --全部车辆离开视野 或 12s------> results
results --再来一局--> countdown（保留参赛者资料，重建赛道/种子/随机参数）
```

- `ending`：**不冻结画面**。车辆继续行驶，冲线车辆以 55% 巡航速度沿终点直线段驶出画面；HUD 显示「比赛结束 · 车辆正在驶离赛道」，并提供「查看成绩」按钮可提前查看。
- `results`：结果面板弹出，**动画仍在继续**（车辆继续移动、镜头锁定不动）；名次以 `ending` 开始瞬间的快照为准，不再变化。

### 赛道生成（阶梯布局 + 真 U 型弯）

- `mulberry32(seed)` 可复现 PRNG；每局新种子，布局为「长直道 → 半圆 U 型弯 → 长直道 → …」的阶梯结构，实测每局 2–3 个 U 型弯。
- **直道（含缓弯）**：横向摆动量直接给定并硬性限制在 55–125 世界单位内 —— 用「航向偏移 = atan(dy/ds)」显式驱动，而不是对曲率积分（后者会累积漂移，实测会让相邻两层直道靠到只剩 300 单位）。两端套 `sin²` 包络，保证进出直道时航向与基准一致。
- **U 型弯**：半径 = 相邻直道间距的一半（390–510），弧长 πR，转角恰好 180°；转向符号逐次交替，每过一个弯整体沿垂直方向前进一个间距、航向翻转 180°，因此各层直道互不重叠。
- 生成后两项数值自检：最小转弯半径（> 1.7 倍赛道半宽）与自相交（任意弧长相差 1200 以上的两点距离必须 > 赛道宽 + 30）；不通过则换种子重滚。实测 5 个种子全部一次通过，层间距 741–788 单位。
- 实测 minR 301–482，约 35% 的赛段半径 < 600（U 型弯段），弯道密度远高于早期「控制点 + 随机振幅」版本。
- 赛道半宽 130 世界单位（约 5 辆车并排）、弧长 9000；起终点各接直线缓冲区（起跑区长度随人数伸缩，冲线后 1400 单位停车区），赛道两端支持线性外推，车辆可一直驶出视野。
- 路缘红白交替**按世界弧长 k×34 分段的四边形贴片**绘制，不再使用 `setLineDash`（其相位从「当前可见段起点」起算，而该起点每帧随镜头移动，会让白条沿赛道一直爬动）；起终点黑白方格线；路面中灰 `#8d9298`，背景浅灰 `#e9edf1` + 淡点阵纹理。

### 速度、超车与脱困规则

- 静态差距收窄（`baseSpeed ±5%`、`accel ±12%`、`startDelay ≤ 0.35s`），让车队始终挤在一起。
- 动态节奏：每车 `pace = 1 + 8.5%·sin(0.37t+φ₁) + 5%·sin(0.93t+φ₂) + 3.5%·sin(0.21t+φ₃)`，周期性发力/疲软，名次持续交换。
- 尾流只在**斜后方**（横向 26–62 单位）有效：跟车者 +9%；正后方改为 −3% 乱流，逼出「拉开 → 抽头 → 超越」的动作，而不是一直黏在前车尾后。
- **车与车可以互相穿过**：不做横向阻挡、不做跟车限速，速度差就能直接超过去（轨迹重叠是允许的）。
- **脱困规则**：若一辆车被前车压住（纵向 < 80、横向 < 46，即车身重叠）持续满 **2 秒**，落后那辆立刻获得 **+45%** 爆发并在 1.8 秒内衰减，直接冲上去。实测被挡计时精确卡在 2.00 秒，每局触发 20–34 次。
- **追赶机制（橡皮筋）**：按名次给位置系数 —— 第 1 名 ×0.94、第 2 名 ×0.96、第 3 名 ×0.98，越靠后越快（最后一名 ×1.14）；真正掉队（落后领先者 400 单位以上）再叠加最多 +12%；掉出前 3 名后每 2–6.5 秒有 55% 概率触发 1.2–3.6 秒的随机冲刺（+5%~12%），一旦回到前 3 名立即暂停。实测领跑交替从 1–3 次/局升到 11–26 次/局，名次交换 14–17 次/秒，完赛首尾差压到 0.2–0.8 秒。
- 基准速度按追赶与爆发的综合效果重新标定（`raceLen/21.5`），第一名仍约 19.5–20.5 秒冲线。
- **终点前 5000 单位淡出整套追赶机制**，改由真实速度 + 终点段微偏置（每局把 ±3% 均分成 n 份随机分配、各车互不相同）决定名次；冲线时刻用**亚帧插值**反推（`t - dt·(超出距离/本帧位移)`），同一帧内冲线也各有精确时刻。显示层再做一次单调化：真实成绩若落在同一毫秒，按名次顺延 1ms，界面上不会出现两个相同时间。
- 时间一律显示到毫秒（`19.110s`）。
- 起步：所有车**挤在同一排**（横向均分整条赛道，允许互相重叠），发车后再各自散开；比赛中除车辆极多（>120 辆，此时不再做逐对处理）外都会保持不重叠。
- 车身全部白色（前翼、鼻锥、侧箱、尾翼、四轮、驾驶舱环），仅用浅灰描边与阴影保持可读；驾驶舱位置显示圆形头像（预乘好黑圈与圆形的贴图），缺图时用彩色首字母圆标。
- **不做任何简化渲染**：车身与阴影预渲染成贴图、头像预乘成圆盘贴图、每车一次 `setTransform` + 1–2 次 `drawImage`，因此 120 辆车也全部是完整车形 + 完整头像（实测 120 车 ≈ 59fps）。
- 车体在世界坐标绘制（变换含 y 翻转），头像与姓名标签在屏幕空间绘制以避免文字镜像；标签互相重叠时自动跳过。

### 镜头

- `racing`：目标 = 当前第一名进度，`focusY = 0.62`；相机朝向取「当前位置 → 前方 330 单位」的方向，弯道中也能把前方赛道与左右边界保持在画面内。
- `ending / results`：目标切换为终点线（`raceLen - 40`），平滑移动后锁定，车辆从镜头前驶过并离开画面。

### 名次面板

排行：已冲线按 `finishTime` 升序 → 未冲线按里程降序 → id 稳定破平局。结算瞬间生成快照，面板列出**全部**参赛者：前 5 名直接可见（前三名有金银铜配色），第 6 名起在分隔线下方，列表区域可上下滑动。

### 与原始规格的差异

- 规格 4.4/5 要求结算后冻结车辆与镜头；按后续要求改为 `ending → results` 两段：先让所有车驶出视野，再弹出可滑动的完整名次。
- 规格 2 要求「速度相差不大、不出现极端碾压」；为满足后续「超车更多」的要求，改为缩小静态差距 + 放大动态节奏差与尾流，结果仍是紧凑车队（首尾差 0.8–1.4s）。
